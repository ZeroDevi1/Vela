# 更新说明

面向用户的 GitHub Release 正文。发版时 CI 读取与 `appVersionName` 对应的 `## x.y.z` 章节。

写法对齐已发布的 `Vela v1.0.0`：一句简介、若干要点、结尾提示选架构。不要写 commit / PR changelog。

## 1.3.19

修复部分影片原画播放时内嵌字幕不显示的问题。

- 修正 PCM 音轨的直放识别，避免《头号玩家》等影片在原画模式下意外转码，导致内嵌 PGS 图形字幕丢失

请根据设备架构选择对应 APK。

## 1.3.18

修复手机版安装包的构建问题，继续提供服务器类型选择与 Peach 请求优化。

- 修复 1.3.17 手机版无法完成构建的问题
- 手机与电视添加服务器时可选择 Emby、Jellyfin 或 Peach，减少连接前的重复检测
- Peach 浏览合并同一会话中的重复请求，减少重复加载

请根据设备架构选择对应 APK。

## 1.3.17

添加服务器时可直接选择类型，Peach 登录和浏览减少重复请求。

- 手机与电视添加服务器时可选择 Emby、Jellyfin 或 Peach；Peach 无需用户名，支持访问口令、密码登录与开放访问
- Peach 连接直接使用对应协议，减少登录前的重复检测与等待
- 合并同一会话中同时发生的重复 Peach 浏览请求，减少重复加载
- 改进返回、切换类型与重复点击时的连接处理，避免过期请求影响新页面

请根据设备架构选择对应 APK。

## 1.3.16

新增 Peach 服务器支持，手机端可直接浏览、播放和管理 Peach 馆藏。

- 添加服务器时可识别 Peach，支持访问口令、密码登录与开放访问
- 支持导入 Peach CA 证书，服务器重签证书后无需再次确认；也可核对并信任服务器公钥指纹
- 手机端新增 Peach 浏览入口，提供名册、原目录、播放列表、关注更新、JAV 探索与图集
- 搜索补全与历史可与 Peach 网页共享，播放时可恢复倍速和字幕选择，并搜索在线字幕
- 详情页支持评分、已看、稍后看、标签、播放列表与资源下载等操作
- 新增 Peach 管理入口，可查看任务、管理订阅与关注、整理文件和标签、维护馆藏；服务器允许时可修改配置，部分功能仍通过应用内网页使用

请根据设备架构选择对应 APK。

## 1.3.15

电视版改成 Emby 风格的界面，遥控器找片更快。

- 媒体库页一行显示 6 张海报，顶部按节目、推荐、收藏夹、类型、单集、文件夹等页签切换，右侧可排序、只看未观看、按类型筛选
- 按标题排序时按拼音排列，左侧首字索引可直接跳到对应位置；排序选择会记住
- 首页顶部显示当前选中影片的标题、简介和背景图
- 详情页改为海报加信息的布局，季、演员和推荐往下翻就能看到，并显示预计结束时间
- 播放器控制条集中到底部，进度条与按钮更清楚
- 搜索支持拼音首字母，例如输入 atm 可以找到「奥特曼」

## 1.3.14

电视版更适合遥控器操作，也能装到更多电视上。

- 电视版改为一个通用安装包，64 位芯片配 32 位系统的电视（如部分 TCL 机型）也能安装，不用再分架构
- 电视桌面显示 Vela 横幅；无触摸屏、只有有线网络的设备不再被安装器拒绝
- 遥控器焦点统一为白色描边高亮，首页、设置、详情、人物页和切换服务器弹窗都能看清当前位置
- 返回键依次回到侧边栏、首页，首页再按一次才退出；从详情或设置子页面返回后焦点停在原来的位置
- 登录页移到输入框时不再自动弹出键盘，按确认键才开始输入
- 手机版切换到私密服务器后直接弹出系统验证，不用再点一次「解锁」
- 拖动进度条时的预览画面出得更快

人物页补上生卒日期和出生地。

- 点进演员后，头部在姓名下方显示出生日期和年龄；已故人物显示生卒日期

## 1.3.12

VR 转平面能识别更多片源，识别不出时也可以手动开启。

- 文件名或标题里只写了「VR」（如 `_VR_`、【VR】、8KVR）的影片会按 180° 自动转平面
- 更多厂牌的 VR 番号可以识别，包括前面带数字的写法
- 分 CD 的影片里某一段识别不出时，沿用其它分段的排布
- 没有识别出但画面比例像 VR 的影片，「更多」菜单里也会显示 VR 转平面，可手动开启并选择投影方式

请根据设备架构选择对应 APK。

## 1.3.11

修复「平面版 + 分 CD 的 VR 版」放在同一部影片下时，分段和 VR 转平面不可用的问题。

- 详情页切换到分 CD 的版本后，会显示该版本的分段（CD1 / CD2 …）
- 从 CD2 回到 CD1 时继续播放原来的版本，不再换成平面版，VR 转平面选项不会消失
- 播完一段后会自动接着播同一版本的下一段
- 仅 Jellyfin 服务器生效

请根据设备架构选择对应 APK。

## 1.3.10

修复部分 MP4 视频硬解播放掉帧，4K 高帧率视频倍速播放更流畅。

- 个别视频（封装时时间戳写入有误）在 MPV 硬解下画面卡顿、帧率减半，软解却正常；现在播放时会自动识别并修正，继续使用硬解
- 修正对其他视频没有影响
- 4K 50/60 帧视频用 MPV 倍速播放（含长按加速）不再卡成幻灯片；这类视频即使硬解选了「MediaCodec (copy)」也会自动改用直接硬解
- 倍速播放时画面缩放临时改用轻量算法，回到正常速度后恢复原设置
- 进度条预览图的后台生成不再和正在播放的视频抢网速，倍速播放时会暂停

请根据设备架构选择对应 APK。

## 1.3.0

8K VR 等超高清片源播放更流畅，VR 视频可以在手机上转成平面观看；经 VPN 访问时不再被服务器强制转码。
