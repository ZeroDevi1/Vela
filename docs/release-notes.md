# 更新说明

面向用户的 GitHub Release 正文。发版时 CI 读取与 `appVersionName` 对应的 `## x.y.z` 章节。

写法对齐已发布的 `Vela v1.0.0`：一句简介、若干要点、结尾提示选架构。不要写 commit / PR changelog。

## 1.2.4

播放器可以静音，拖动进度时主画面不动、小窗显示目标位置；书籍、音乐和发现也补进了日常使用。

- 音轨增加静音，详情页和播放器都会记住
- 拖动进度条时主画面保持不动，小窗显示客户端抽出的关键帧；同一秒内的帧会复用
- 预览缩图改在 GPU 上完成，并复用播放器缓存，4K 与 10bit 片源拖动更跟手
- 按 Emby / Jellyfin 的片头、片尾标记跳过，并支持上一集和下一集
- 支持书籍阅读、漫画按页加载，以及后台音乐播放
- 发现、多源搜索、订阅日历和 Trakt 跟踪
- 单台服务器可开启私密访问，应用保持打开时只需验证一次；兼容 Jellyfin 12
- 修复启动闪退，以及详情里视频版本串到其他影片

请根据设备架构选择对应 APK。

## 1.2.2

部分 4K HEVC 硬解会偏色发红；这类片自动改走软解，颜色与网页转码一致。

- 未标注色域、`hev1` 或 4K 的 HEVC SDR 优先软解，避免 MediaCodec 用错色域
- 已正确标注的 1080p HEVC / H.264，以及真正的 HDR10，仍走硬解
- 不再把仅标注 BT.2020 的 SDR 误判成 HDR

请根据设备架构选择对应 APK。

## 1.2.1

字幕和音轨更好认；多台同名 Jellyfin 会分开保存，服务器页也能直接删掉当前这台。

- 选轨时展示更完整的字幕 / 音轨信息；同一部剧会记住上次选的轨
- 手机播放器可按宽度等比调整画面
- 添加服务器不再按用户名或实例自动合并，多地址请在配置里手动加线路
- 服务器列表进入时不再预选，任意一台都可以移除

请根据设备架构选择对应 APK。

## 1.2.0

手机端可把 VR / 180 / 鱼眼片转成平面观看；多 CD 影片能在详情里切换分段。

- 识别 VR 片源后，播放器底栏出现芯片，点「VR · 转平面」才改变画面
- 开启后可拖动视角、双指调整视野；左右边缘仍调节亮度与音量
- 详情页展示 Jellyfin 叠片后的 CD1 / CD2 等分段，可点选播放

请根据设备架构选择对应 APK。

## 1.1.0

手机端媒体库海报更清晰；页面进入与返回转场更完整。

- 媒体库海报、横图与 Banner 按更高分辨率请求，减少发糊
- 进入详情等页面时从右侧滑入；返回时整页滑出
- 小米/红米 HyperOS 侧滑返回时也会播放完整退出动画，不再几乎无动画

请根据设备架构选择对应 APK。

## 1.0.3

播放设置增加杜比开关；从播放器返回演员或详情页时不再整页刷新。

- 设置「画面」增加杜比亮度增强（默认开，仅作用于杜比视界）与 DV Profile 7 转 8.1（默认关，改完需重开当前片）
- 设备不支持杜比视界时回退 HDR10 / SDR，避免黑屏
- 从播放器返回演职员或影片详情时保留已加载内容，不再闪成加载态

请根据设备架构选择对应 APK。
