## 1.3.4

「识别」回到电影和剧集入口，VR 竖屏铺满画面；播放失败时会显示原因，并可让服务器转码为 4K 后重试。

- 「识别」与「取消识别」只在电影和剧集上提供：识别作用于整部剧，不再出现在单集和季的菜单里
- VR 影片竖屏播放时铺满屏幕
- 播放出错时显示错误原因；片源宽于 4K 时可选择「服务器转码为 4K」重试（也可在「更多」菜单中使用）
- 新增「视频首选版本」（界面设置）：同一条目有多个版本且未手动选择时，按默认、最高分辨率、最高码率、最佳动态范围或指定分辨率起播
- 新增「长按播放键退出播放器」选项（播放设置，默认关闭）

请根据设备架构选择对应 APK。

## 1.3.3

多 CD 影片的每个部分都能正常播放了；VR 影片打开即是平面画面，应用更新在国内下载更快。

- 修复多 CD / 分段影片只有第一部分能播放的问题，从任一部分进入都能在播放器里切换全部分段
- VR 影片默认开启转平面，仍可在播放器里随时关闭
- 设置中的「服务器」改为直接弹出切换窗口，切换、添加或删除账号不再跳回应用首页
- 应用更新下载新增「自动」加速：自动测速选择最快的节点，下载失败会换节点重试，并校验安装包完整性
- 移除 Discord 动态分享功能

请根据设备架构选择对应 APK。

## 1.3.2

字幕不再冲出屏幕，VR 转平面看得更近、转视角更顺；多 CD 影片在播放器里可以直接切换各部分。

- 长句字幕自动换行；ASS 兼容模式下字幕位置也可以调整
- VR 转平面默认视角拉近，主体更清楚；转视角不再卡顿，按住拖动不会误触倍速，底部横向拖动仍可调进度
- 超高清与 VR 片源不再在后台预生成进度缩略图，播放更流畅
- 多 CD / 分段影片新增播放列表，播完自动接续下一部分
- 媒体信息面板改版，字号更大、分组更清晰；VR 投影格式补上图标

请根据设备架构选择对应 APK。

## 1.3.1

播放器重新设计，横屏比例、转场和返回都更顺滑；管理员可以在应用里直接识别、改图、改字幕和编辑元数据；弱网下媒体库和详情页也能秒开。

- 播放器补齐顶栏工具、电量时间网速、截图、锁定、倍速和定时关闭，进度条改为跟随播放流动的波浪样式
- 修复横屏时 4:3 等比例的视频被裁切，画面完整显示
- 横竖屏切换不再黑屏重新加载，进出播放器改为缩放淡入淡出，返回不再卡顿
- 支持系统预测性返回，侧滑时页面跟手缩小，松手后连贯退场
- 新增编辑元数据、修改图片（远程搜索、上传、删除）、修改字幕（搜索下载、删除）和识别，兼容 Emby 与 Jellyfin
- 媒体库和详情页会缓存上次的内容，再次进入立即显示并在后台刷新，断网时也能浏览
- 播放时界面刷新和视频渲染开销大幅降低，播放更省电

请根据设备架构选择对应 APK。

## 1.3.0

8K VR 等超高清片源播放更流畅，VR 视频可以在手机上转成平面观看；经 VPN 访问时不再被服务器强制转码。

- 5.7K / 8K 等超高清片源自动改用轻量渲染，8K VR 由约 15 帧提升到接近 60 帧
- VR 转平面恢复可用，全程硬解零拷贝；拖动视角跟手，双指缩放视野
- DMM 系 VR 默认按 180° 左右眼展开，减少画面边缘拉伸
- 文件名带 VR、实际已是平面的视频不再被误识别为 VR
- 服务器仅因码率上限拒绝直放时，「原画」模式直接播放原始文件，避免 4K / 8K 实时转码一直加载
- 8K HEVC 不再走额外的拷贝解码路径

请根据设备架构选择对应 APK。

## 1.2.4

播放器可以静音，拖动进度时主画面不动、小窗显示目标位置；书籍、音乐和发现也补进了日常使用。

- 音轨增加静音，详情页和播放器都会记住
- 拖动进度条时主画面保持不动，小窗显示客户端抽出的关键帧；同一秒内的帧会复用
- 预览缩图改在 GPU 上完成，并复用播放器缓存，4K 与 10bit 片源拖动更跟手
- 按 Emby / Jellyfin 的片头、片尾标记跳过，并支持上一集和下一集
- 支持书籍阅读、漫画按页加载，以及后台音乐播放
- 发现、多源搜索、订阅日历和 Trakt 跟踪
- 单台服务器可开启私密访问，应用保持打开时只需验证一次；兼容 Jellyfin 12
- 修复启动闪退，以及详情里视频版本串到其他影片

请根据设备架构选择对应 APK。

## 1.2.2

部分 4K HEVC 硬解会偏色发红；这类片自动改走软解，颜色与网页转码一致。

- 未标注色域、`hev1` 或 4K 的 HEVC SDR 优先软解，避免 MediaCodec 用错色域
- 已正确标注的 1080p HEVC / H.264，以及真正的 HDR10，仍走硬解
- 不再把仅标注 BT.2020 的 SDR 误判成 HDR

请根据设备架构选择对应 APK。
